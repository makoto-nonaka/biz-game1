# 管理者向け ラウンド解説と分析記録

## 解説の読み方

ラウンド集計後、管理者画面の「各ラウンドの差がついたポイント」に解説が表示されます。比較対象は各回の利益順位です。累計順位とは区別し、2回目以降はその回までの累計首位も示します。最新回を開き、過去の回は折りたたみます。

当回利益首位と、次に異なる利益の会社を比べ、利用者数・固定費の差と、利益差の大きな内訳を示します。同率首位の場合は代表1社の比較例であることを明示し、全社同額・1社だけの場合は勝因を断定しません。首位も赤字であれば、そのことを表示します。

利益差の内訳は、利益 = 利用者数 × 1人あたりの利益への貢献 − 固定費を用います。人数の差に両社の平均貢献額を掛けた部分、貢献額の差に両社の平均人数を掛けた部分、固定費の差の3つに分けると、合計は実際の利益差と一致します。この算術的な分解は、現実の因果関係の推定ではありません。

「比較計算の条件を見る」では、上位社の市場配分、ビジネスモデルと価格、開発投資、広告投資を、それぞれ比較相手の選択と同じにした場合の利益を確認できます。モデルと価格はFreeの価格0円などの整合を保つため一組です。他社の選択と以前の開発経験は固定し、該当ゲームの版の計算式で再計算します。1位の選択でも改善余地がある場合は、その点を説明します。

比較は1項目ずつの別計算です。複数項目の効果は相互に関係するため足し合わせられません。これからの他社の判断も予測しません。解説に生成AI・外部API・APIキーは不要です。

## 記録の保存

管理者画面の「分析用の記録を保存」で「CSVを保存」または「テキストを保存」を押します。全ラウンドをまとめて出力します。最終回を終える前にも保存でき、その時点の記録になります。

CSVは1社×1ラウンドの1行です。項目は、ゲーム名・参加コード・出力日時UTC・進行状況・モデル版、会社ID・会社名・確定状況、当回利益順位・累計利益順位・累計利益、全意思決定、OS別と合計の人数、販売課金収入・受取広告収入・売上、基本運営費・移行費用・固定費・変動費・総費用・当回利益、1人あたり売上・分岐点、OS別の期首・期末開発資源、顧客タイプ別人数、市場人数と未獲得人数、当回解説・比較計算JSON・計算ルールJSONです。

UTF-8 BOM付き、カンマ区切り、CRLF改行です。カンマや引用符を含む会社名・解説中の改行も引用して保持します。ゲーム名・会社名などが数式として処理されないよう、数式記号から始まる文字列には先頭にアポストロフィを付けます。赤字を表す負の数値はそのままです。

テキストは各回の解説と会社別の項目を順番に読める形式です。比較計算の変更条件と利益も含めます。

集計前は提出済みの選択と未確定の会社を区別します。未確定の選択・未集計の結果、旧版で記録されていない開発資源や顧客タイプ別人数は、CSVでは空欄です。画面で選択中でも未確定の内容はサーバーに送られていないため出力できません。

## 権限と既存ゲーム

解説と出力は管理者専用です。認証は既存の管理者トークンで行い、プレイヤーからの出力要求は拒否します。ファイルに操作トークンは含みません。管理者用の記録には他社の非公開情報が含まれます。

過去の結果を書き換えず、保存済みの選択と結果から解説を組み立てます。v0.2〜v0.5の既存ゲームに対応し、未記録の項目は補作しません。今回の機能追加だけなら新しいゲームの作成は不要です。別のバランスで遊びたい場合だけ新しいゲームを作ります。

## 開発者向け

GET `/api/games/:code/export?format=csv` または `format=txt`。AuthorizationのBearerトークンで管理者を確認します。URLにはトークンを付けません。
管理者用ゲーム状態にはanalysisを追加し、プレイヤー用の状態には付けません。

Node.js 22以上で `npm test`。解説の比較再現、利益差の合計、CSVの読み戻し、日本語・引用符・数式対策、未確定状態、秘密情報の除外、旧版、API権限、再起動後の利用を検証します。
