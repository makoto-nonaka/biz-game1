# 50分の模擬講義での進め方

## 到達目標

「誰に何をいくらで売るか」を選び、売上・費用・利益・損益分岐点を自分の会社の数字で説明する。他社の選択を含めて結果を振り返り、次の仮説を1つ立てる。

## 事前準備

- 運営管理者用PC1台、プレイヤー20〜30人各スマホ1台。事前に学校の接続環境を確認。
- 運営管理者はURLを板書・投影し、ゲームを作成して参加コードを伝える。
- プレイヤーは本名不要の会社名を1つ登録。二重登録せず、再接続は同じ会社に戻る。
- 全員が確定するまで集計しない。参加者の操作が止まっている場合は声をかける。

## 時間配分

| 時間 | 行うこと | 運営管理者の問い |
| --- | --- | --- |
| 0〜6分 | 身近なアプリのビジネスを考える | 売上が多い会社は、利益も多いだろうか？ |
| 6〜11分 | 登録・ルール・費用の説明 | 500円で1人に売ると、固定費回収にいくら使える？ |
| 11〜19分 | 第1回：戦略を選び、確定・集計 | 誰に売る？ なぜその価格・投資にした？ |
| 19〜25分 | 結果と損益分岐点を計算 | 売上−費用は？ 必要な顧客数に届いた？ |
| 25〜33分 | 第2回：他社を見て修正・集計 | 1つ変えるなら何？ 追加投資は何人で回収？ |
| 33〜41分 | 第3回：仮説を再検証・集計 | 自社が同じ選択でも結果は同じになる？ |
| 41〜50分 | 全体共有と経営学への接続 | 利益以外に大切にしたいものは？ |

## 結果を待つ間の短いメモ

紙または端末のメモに残します（アプリ内の回答保存機能はありません）。

1. 今回の戦略を選んだ理由を1文で。
2. 固定費はいくら？ 損益分岐点は何人？
3. 結果を見て、予想との違いは何だった？
4. 次回は何を変え、どうなると予想する？

## ビジネスモデルを比べる問い

- Freeでは無料の利用者が増えても、どこから売上が生まれる？
- 自社が払う「広告投資」と、自社が受け取る「広告収入」はどう違う？
- Freemiumの課金率40%・課金価格500円なら、1人あたりの課金収入はいくら？無料利用者の広告収入も足すと売上はいくら？
- 利用者数が最多の会社と、利益が最大の会社は同じ？
- Android・iOSへの配分を変えたとき、獲得した人数の比率も同じになる？

## 開発資源と市場変更を考える問い

- 第1回の開発投資は、第2回の自社にどんな違いを残した？
- 同じ価格・当回投資でも、利用者数に違いが生まれたのはなぜ？
- 元の市場の経験を活かすことと、別の市場へ移ることをどう比較する？
- 市場移行費用を払ってでも、変更する価値がありそうな状況は？
- 広告は当回限り、開発経験は蓄積する。この違いから投資をどう考える？

## 比較の切り口

- 顧客数の1位と利益の1位を比べる。
- 同じ市場・同じ価格で投資が違う会社を比べる。
- 競合数が多い市場と少ない市場を比べる。
- 前回と同じ選択をした会社の結果が変わった理由を探す。

計算式の指数部分をプレイヤー全員が計算する必要はありません。「価格・開発・広告で魅力度が決まり、市場内で顧客を取り合う」という考え方を確認し、プレイヤーは売上・費用・利益・損益分岐点に集中します。

## 最後に伝えたいこと

経営は決まった正解を当てる作業ではなく、仮説を立てて選び、結果から修正する営みです。今回の順位は3回の利益だけで決めましたが、実際の企業には顧客への価値、働く人、品質、信用、将来の成長などもあります。「このゲームに1つ指標を加えるなら何にする？」で締めくくると、原教材の企業価値・無形資産の視点にもつながります。
