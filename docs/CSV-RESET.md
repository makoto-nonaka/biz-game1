# チームキーCSVの読み込みとリセット

管理入口、またはゲーム管理画面の「チームキーCSVからゲームを読み込む」でCSVを選びます。従来の「チームキーCSVを保存」で出力したファイルを使えます。UTF-8（BOM付き可）、最大30チーム、1ファイル1ゲームです。「参加コード／ゲーム番号／ゲームコード」のいずれかと「チームキー」を必須列として読み取り、チーム名と除外状態もあれば復元します。端末数は設定として読み込みません。

新規復元ではCSVのゲーム番号をそのまま使用し、ゲーム名とラウンド数を画面で指定します。チーム名が入っていれば、最初に参加した端末を代表者とします。CSVにない成績・開発経験・端末情報・運営用ゲームキーは復元できません。

同じゲーム番号が既にある場合は、同じ運営権限と同じチームキー一覧であることを確認し、既存ゲームを開きます。進行や参加情報は変更しません。別のブラウザでは先に運営用ゲームキーから該当セッションを呼び出してください。チームキーCSVだけで既存ゲームの運営権限を取得したり、別のゲームを上書きしたりはできません。

1ラウンド以上集計した後、「1ラウンド目からリセット」でやり直せます。リセット後のラウンド数を1〜4から選び、確認欄にチェックして実行します。参加中の全チームが対象です。

維持するもの：ゲーム番号、チームキー、チーム名、参加対象チーム、参加済み端末、代表者、操作権限、計算モデル。
初期化するもの：現在の意思決定と下書き、結果履歴、累計利益、開発資源・経験、前回配分に基づく移行費用、現在のラウンド。

リセット後は受付画面には戻らず、同じ参加チームでラウンド1の意思決定受付へ進みます。再参加・ログイン・名前の再登録は不要です。画面表示中の端末は通常約3秒で更新されます。非表示にしていた端末は画面に戻ったときに更新されます。リセット前の古い画面からの操作は、実行回の番号を確認して拒否します。

リセット前の成績はサーバー内の別記録として保存し、管理画面の「リセット前の記録を保存」からCSV・テキストを出力できます。元の成績へプレイを巻き戻す機能ではありません。

当日の推奨運用：1つのゲームをプレ1回で開始 → 集計 → 同じゲームのリセット後の回数を3回にして実行 → 本番を開始。同じ番号・キー・端末で進められます。前回までに作ったプレ／本番の別ゲーム方式も継続利用できます。
