SmartApps Biz Game 数字チームキー・画面整理版（2026-10-28）

変更内容
・新規発行するチームキーは100000～999999の6桁の数字。同一ゲーム内では重複しません。
・プレイヤー入口は参加コードとチームキーだけにし、旧形式の会社名入力欄を削除。
・指定されたキャッチコピー、会社数の表示、大文字・小文字に関する案内を削除。
・プレイヤーのチーム画面からバランスの版・課金率・広告収入のバナーを削除。
・管理者の新規ゲーム作成、およびCSVから新規復元する際のラウンド数初期値は4。
・管理者画面から2セッションの事前準備・呼び出し・切り替えの操作欄を削除。
・単独ゲーム作成、参加QR、チームキーCSV保存と読み込み、リセットは引き続き利用可能。

GitHub / Renderの更新手順
1.「更新ファイルのみ.zip」を解凍します。CSV読み込み・リセット版以前の場合は「プログラム一式.zip」を使ってください。
2. GitHubのリポジトリのCode画面で「Add file → Upload files」を選びます。
3. 解凍したフォルダを開き、中のpublic、lib、server.js等をリポジトリのルートへドラッグします。
   ZIPそのものや外側のフォルダをアップロードしないでください。publicとlibの階層を保ってください。
4.「Commit changes」で保存します。
5. RenderのデプロイがLiveになったら、管理者・プレイヤーともページを再読み込みします。
6. 新規ゲームを作成し、4ラウンドが初期選択されること、発行キーが数字6桁になることを確認します。

既存データについて
既存のゲームやログイン情報、英数字のキーを自動で変更することはしません。
新しい参加画面とCSV読み込みは数字6桁専用です。英字を含む旧キーで新しく参加・CSV復元したい場合は、
この版で新規ゲームを作成し、数字キーのCSVを保存し直してください。
既にログインしている端末の既存ゲームは、そのまま継続できます。
既存ゲームの設定済みラウンド数は変更しません。リセット時の選択はそのゲームの現在設定を引き継ぎます。
ゲームバランスの計算パラメーターは変更していません。
データフォルダ、.env、実際の参加キーや成績はZIPに含めていません。
public/config.jsをVercel等で個別設定している場合、一式版の既定値で上書きしないでください。
