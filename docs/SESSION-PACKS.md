# 事前発行と印刷

管理画面の「2セッション分を事前準備する」で、プレ1回＋本番1〜4回を2セット作成します。各セッションに12桁の運営用ゲームキーを発行し、プレと本番の2ゲームを紐付けます。各セット内で同じ6桁のチームキーを使い、名前・端末・成績・開発資源はゲームごとに独立します。セッション間はキーも成績も別です。

「チーム配布票を印刷」で参加コード・チームキー・プレ用QR・本番用QRをA4縦の切り取りカードとして印刷できます。15チーム×2セッションは6ページです。チーム数と印刷対象セッションを選択して「表示を更新」してください。各チームに1枚配布し、全員が同じキーで入ります。共有QRにはチームキーや運営権限を含みません。

「運営用控えを印刷」には12桁の運営用ゲームキーを含むため、運営側だけで保管してください。端末が変わっても、公開サイトの管理入口でこのキーを入力すると、そのセッションのプレと本番を呼び出せます。キーは大小文字・ハイフン・空白を区別しません。管理者の長い操作トークンをURLに入れることはありません。

参加枠は20を事前発行して15枠だけを配布すれば、5枠を予備にできます。未使用枠はそれぞれのゲームの受付締切時に参加対象外になります。追加発行はプレと本番の両方が受付中の場合だけ可能で、両ゲームに同じキーを同時追加します。片方を開始した後は、事前発行済みの予備枠を使ってください。

本番への移動は運営管理者のボタンで管理画面を切り替え、参加者は本番QRを読み直して同じチームキー・チーム名を登録します。自動移行ではありません。名前・代表者の登録も本番で行うため、運営では移行に約3分を見込んでください。

公開サイトの管理画面で発行・印刷してください。ローカルの確認用QRを配布するとスマホから公開サイトを開けません。Renderの保存領域を消さないでください。画面を再デプロイしても、元の保存データが必要です。

印刷ページは作成・再開した管理者ブラウザの保存情報を使います。他の端末では先に管理画面から運営用ゲームキーを入力してください。初期表示では直近2セットを選択します。印刷前にセッション名・参加コードを確認してください。
