SmartApps Biz Game ゲーム一覧・番号再利用版（2026-10-28）

できること
・管理画面（admin.html）の「作成済みゲームの管理」にゲーム番号、ゲーム名、進行状況、登録数、作成日時を表示します。
・「管理画面を開く」で、既存ゲームをそのまま再開できます。
・「無効化（番号を空ける）」で選んだゲームを退避し、同じ番号を再利用できます。
・同じ番号のチームキーCSVを読み込むと、番号・キー・会社名を引き継いだ新規ゲームを作れます。
・「無効化したゲーム」から、番号が空いていれば元のゲームを戻せます。
・1人用コンピュータ対戦は一覧の対象外です。

最初の更新手順
1. 更新前に、必要なゲームのチームキーCSVと、結果CSV／テキストをPCへ保存してください。
   Render無料プランは再デプロイ時にサーバー保存データが失われます。退避記録も同じ保存領域です。
2.「更新ファイルのみ.zip」を解凍します。前回の数字キー版を反映済みであれば、これだけで更新できます。
   以前の更新を飛ばしている場合は「プログラム一式.zip」を使用してください。
3. GitHubリポジトリのCode画面で「Add file → Upload files」を開き、解凍した中身をアップロードします。
   server.js、public、test、docs等をルートに置きます。ZIPそのものや外側のフォルダを置かないでください。
   public/game-manager.js が新しい必須ファイルです。public/app.js だけの更新では動きません。
4. Commit changes で保存します。Renderで最新デプロイがLiveになったことを確認します。

Renderで運営専用パスワードを設定（最初に一度）
別のPC・ブラウザで作ったゲームを含めて、全ゲームを管理するための設定です。
1. Render Dashboardで、このゲームのWeb Serviceを開きます。
2. 左の Environment → Environment Variables → Add Environment Variable。
3. Key は ADMIN_PASSWORD、Value は運営側だけが知る十分長いパスワード（目安16文字以上）を入力します。
   ここに実際のパスワードを記入したファイルをGitHubへアップロードしないでください。
4. Save and deploy を選びます（Save, rebuild, and deployでも可）。Liveになるまで待ちます。
   Save onlyでは、次のデプロイまで反映されません。
5. admin.htmlを再読み込みし、「作成済みゲームの管理」を開きます。
6.「運営専用パスワードで全ゲームを表示」にパスワードを入力します。
   既存の保存データが残っていれば、以前の版で作成したゲームも表示できます。
   表示できるのはサーバー上に現存するゲームだけです。既に失われた場合はCSVから新規復元してください。
公式手順：https://render.com/docs/configure-environment-variables

今回の123番の例
A. 既存ゲームをそのまま利用する場合
1. admin.htmlのゲーム一覧に123番を表示します。
2.「管理画面を開く」を選びます。
3. 必要なら受付・集計を続けます。番号・チームキー・既存端末は変わりません。

B. CSVを使って最初から新しい123番を作りたい場合
1. ゲーム一覧の123番の「無効化（番号を空ける）」を押します。
2. 確認欄に123と入力し、「このゲームを無効化する」を押します。
3.「チームキーCSVからゲームを読み込む」で、PCに保存した123番のCSVを選びます。
4. ラウンド数（初期値4）を選び、「CSVの設定で読み込む」を押します。
5. 同じ123番・同じチームキーで、新しい受付を開始できます。
   サイトURLが同じなら、印刷済みの「/?code=123」のQRコードをそのまま使えます。
6. プレイヤーは紙のQRコードから入り、元の数字6桁のチームキーで参加し直します。
   CSVに会社名があれば復元され、最初に入った端末が代表者になります。

無効化とリセットの違い
・無効化→CSV読み込み：新しいゲームとして作り直します。旧端末のログイン情報・成績・意思決定は新ゲームには引き継ぎません。
・「1ラウンド目からリセット」：従来どおり、会社名・キー・端末を維持して、ログアウトせず最初から選び直します。
・無効化した記録を戻す場合は「無効化したゲーム」→「元に戻す」。同じ番号が使用中なら戻せません。
  元のゲームを戻した場合は、そのゲームの保存時点の成績と端末情報も戻ります。

パスワードを使わない管理
・この版以降は、管理画面を開いたゲームの管理権限をブラウザに複数保存します。
・同じブラウザであれば、保存済みのゲームを一覧から開く・無効化できます。
・以前の版では最後に使ったゲームの情報しか残っていないことがあります。
・ブラウザの保存情報を消した場合や別PCを使う場合は、ADMIN_PASSWORDによる全ゲーム管理を利用してください。
・CSVに含まれる参加コードやチームキーだけでは、他の既存ゲームを無効化できません。
・全ゲーム管理の認証はタブに保存し、有効期間は12時間。サーバー再起動後は再入力が必要です。
・「全ゲームの管理を終了」で専用認証を終了します。個々のゲームの管理権限はブラウザに残ります。

保存と互換性
・ゲームの経済モデル、数字6桁のチームキー、ラウンド初期値4回は変更していません。
・退避データもサーバーのgames.json内に保存します。無料プランの休止・再起動・再デプロイへのバックアップではありません。
・ZIPに実データ、参加キー、成績、運営パスワードは含めていません。
・Vercel等でpublic/config.jsを個別設定している場合、一式版の既定値で上書きしないでください。
